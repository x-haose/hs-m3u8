# ADR-0004：产品范围只做 HLS

- 状态：已采纳
- 日期：2026-10-09

## 决定

1. 产品只做 HLS，并把它做到最好：站点适配回调、加密、音视频分离、资源嗅探、直播录制。
2. HTTP 直链多线程下载、BT、磁力不在当前范围。以后要做时不自己手写协议实现，优先评估集成现成的下载器（如 aria2），届时再定。
3. 核心库不为其他协议预留抽象。以后接入外部下载器时，多协议的任务管理放在桌面应用层，用任务类型区分 HLS 任务与外部下载器任务。

## 理由

- HLS 是这个产品区别于通用下载器的地方；BT 与磁力是完全不同的领域（DHT、tracker、对等协议、做种、端口映射），自己实现等于再做一个 qBittorrent，还会带来与盗版关联的分发风险。
- 只为将来可能的协议在核心里预设抽象，说不出它现在防的是什么问题。

## 以后集成 aria2 时要先评估的事实（2026-10-09 查 GitHub）

- 许可证 GPL-2.0。以独立进程 + JSON-RPC 通信不构成链接，可随应用分发，但需附许可证并提供对应源码。
- 最后一个正式版 1.37.0 发布于 2023-11-15；官方自 1.35.0（2019-10）起不再提供 macOS 二进制，arm64 需自行编译。
- Motrix 2.0（Electron，2026-10 仍在发 beta）使用 aria2，但用的是 Motrix 自己维护的分支。
- 备选：HTTP 直链复用本项目的 HTTP 基础设施自行实现；BT 用 librqbit（9.0.1，2026-08-20，Apache-2.0）。
